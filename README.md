# 盒音工坊 · BoxTone

> 给你的华为蓝牙耳机换个充电盒开盖音。
>
> HarmonyOS 应用 · 中英文界面 · 当前版本 v1.2.1

连接耳机 → 选内置音效或导入素材 → 裁到 2.5 秒 → 写入充电盒。

---

## 功能

- **9 个内置音效**，也可以导入 MP3 / M4A / AAC / FLAC / OGG / WAV
- **波形编辑**：拖动选区裁剪，调节起始位置、时长、增益，支持峰值归一化与淡入淡出
- **双引擎试听**：原声听素材本身，盒音听写入耳机后的真实效果
- **一键写入**：生成后直接写进充电盒，不满意可随时恢复默认开盒音
- **音效库**：搜索、排序、重命名、批量删除，可分享到微信 / QQ
- **备份恢复**：整库备份为单个文件，也支持导入 `.pcm` / `.raw`
- **诊断日志**：写入失败时直接告诉你下一步该做什么，而不是只给一个错误码

## 音效规格

写入充电盒的音效需符合以下规格，应用会自动转换。

| 参数 | 值 |
|:--|:--|
| 编码 | Signed 16-bit PCM（小端） |
| 声道 | 单声道 |
| 采样率 | **16700 Hz** |
| 容器 | 无文件头 RAW（`.pcm` / `.raw`） |
| 时长 | ≤ 2.5 秒 / 83500 字节 |

> 盒端解码器标定在 16700Hz 而不是标准的 16000Hz。用 16000Hz 素材播放时音调会整体升高约一个半音，
> 所以应用统一按 16700Hz 转换。
>
> 2.5 秒的上限来自实测：鸿蒙侧 SPP 传输约 23KB/s，单条音效超过约 106KB（3.2 秒）后，
> 耳机在擦写阶段会失去响应。详细数据见 [`docs/write-duration-gap.md`](docs/write-duration-gap.md)。

## 构建

需要 **DevEco Studio** 与 **HarmonyOS SDK**（沉浸光感底栏依赖闭源的 `@kit.UIDesignKit`，
OpenHarmony 开源 SDK 中没有）。首次打开工程并等待 Sync 完成，会自动生成 `hvigorw` 包装器。

```bash
./tools/dev.sh build                # 调试包，可直接安装
./tools/dev.sh build release debug  # release 编译 + 调试签名，用于验证混淆后的行为
./tools/dev.sh build release        # 发布包，用于上传应用市场
./tools/dev.sh install              # 安装到已连接的设备
./tools/dev.sh log                  # 查看应用日志
```

发布签名的包无法通过 `hdc` 侧载安装，只能经应用市场分发；本地验证请用调试签名版本。

## 已知限制

- **自定义音效最长 2.5 秒**：受传输带宽与固件擦写稳定性限制，详见上方说明
- **仅经典蓝牙可写**：星闪链路没有对三方开放的串口通道，星闪连接时会提示切换
- **无法读取耳机当前音效与电量**：私有协议未公开读取接口，恢复默认通过「选中默认槽位」完成
- **仅 arm64-v8a**

## 隐私

- 不读取设备 SN，日志中的蓝牙地址统一打码
- 音效、设置、日志全部保存在本机，不上传任何服务器
- 反馈通过系统分享发送，由你自行选择渠道
