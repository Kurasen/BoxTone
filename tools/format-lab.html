盒音工坊 · 格式验证台

在电脑上跑一遍与 App 完全相同的转换链：下混 → 裁剪 → 归一化 → 窗口化 sinc 重采样 → 淡入淡出 → 16bit 量化。
同一套 DSP
这不是 App 本身。HAP 需要 DevEco 的 ArkTS 编译器与资源编译器才能产出，且沉浸光感底栏来自闭源 @kit.UIDesignKit，只能在装了 HarmonyOS SDK 的机器上编译。 所以这里做的是去掉界面外壳、保留全部音频算法的验证工具 —— 它能证明「导出的字节流是否合规」这件最容易出错的事，导出的 .pcm 与 App 生成的是同一串字节。
